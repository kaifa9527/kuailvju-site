# 快旅居 · 网站页面预览

长租房、民宿房、旅居置换与物业托管的中英双语响应式测试站。当前所有房源、图片和价格均为示意，不能据此真实预订、置换或交易；此版本不会收集用户联系方式。

## 可操作测试流程

- 长租房页 → 城市、区域、计划起租日与半年/一年精搜 → 按整个租期检查本机测试库存 → 详情联动半年租金上浮 10%、押一付二/押二付一及申请表。
- 民宿房页 → 城市、区域、日期、人数和更多条件精搜 → 详情（图片、设施、地区、规则与费用）→ 选择按日租住。正常水电已含在按晚房价中；民宿不参与置换。
- 按日租住 → 携带入住、退房日期和人数提交意向 → 站内工作台推进处理。
- 旅居置换页只展示明确授权的委托租赁长租房。申请人可选测试房源、已登记的房源，或在申请时登记自己的房源并明确授权。新提交房源出现在本机“待核验”区，不能被其他用户申请入住。
- 双房源置换申请 → A/B 房源、各自入住天数、面积、卧室与装修对照 → B 同意、拒绝或修改时间 → 平台核验。价格与地段仅供参考，不自动换算补差。每位住客每次支付人民币 600 元等值保洁费，覆盖入住前后两次保洁；押金按实际入住房源一个月租金，芭提雅按确认时等值泰铢收取。置换水电按实际抄表结算。
- 置换双方确认后，两个入住段各自占用房源日历，退房后预留完整一天用于保洁与验房。搜索结果可显示缓冲日之后的预计可租档期，但平台未确认对应房源的验房前，下一笔入住不能最终锁定；工作台可分别模拟两个入住段的验房结果。
- 物业托管独立入口 → 选择委托租赁、委托经营或委托看护 → 填写非个人资料字段。仅委托租赁表单可独立授权置换展示，并选择独家或非独家长期委托；未勾选置换时提交会再次提示，可继续不加入。已授权登记自动生成本机待核验展示卡。

测试记录仅保存在当前浏览器的 `localStorage`。工作台的 A、B、平台切换只是单浏览器流程演练，**不是实际账号权限系统**；本机测试的暂占与冲突提示也不能保障跨设备实时锁房。非独家委托房源在测试确认前须勾选外部档期已核实，真实服务仍需人工核查。不会给业主或平台发邮件，也不会收款。请勿输入真实个人资料。未来接入独立后端后，才可实现跨设备申请、原子锁房、真实身份核验、合同、通知、支付及后台审计。

置换页的档期是滚动生成的测试数据，用来验证日期筛选和不可选日期；价格、补差额与房态均须由正式平台核验。示意房源不提供真实评价、精确地址或即时确认。

## 本地预览

```bash
npm ci
npm run dev
```

## 自动发布

`main` 分支每次推送后，GitHub Actions 运行测试、构建并发布至 GitHub Pages。正式可查看的更新以成功部署为准。开发过程中的每次保存不会自动公开，避免半成品或错误代码出现在预览站。

本仓库只包含可公开的网页代码和示意图片。产品需求、合同设计和客户资料保存在仓库外。生产版需要独立接入真实房源、身份资格核验、工单、支付和签署等后端服务。
