# 快旅居 · 网站页面预览

房屋租赁、旅居置换与物业托管的中英双语响应式测试站。当前所有房源、图片和价格均为示意，不能据此真实预订、置换或交易；此版本不会收集用户联系方式。

## 可操作测试流程

- 旅居置换页 → 城市、区域、日期、人数和更多条件精搜 → 民宿详情（图片、设施、地区、测试日历、规则与费用）→ 选择按日租住或业主置换。
- 按日租住 → 携带入住、退房日期和人数提交意向 → 站内工作台推进处理。
- 委托经营业主 → 双房源置换申请 → A/B 房源与异期日期对照 → B 同意、拒绝或修改时间 → 平台核验。对等房源可免费置换；若需补差额，平台提出金额、币种与支付方，A/B 再分别确认，最终由平台确认。
- 三类物业托管页 → 填写非个人资料字段 → 生成测试登记记录。

测试记录仅保存在当前浏览器的 `localStorage`。工作台的 A、B、平台切换只是单浏览器流程演练，**不是实际账号权限系统**；不会给业主或平台发邮件，也不会收款。请勿输入真实个人资料。未来接入独立后端后，才可实现跨设备申请、真实身份核验、库存与合同校验、通知、支付及后台审计。

置换页的档期是滚动生成的测试数据，用来验证日期筛选和不可选日期；价格、补差额与房态均须由正式平台核验。示意房源不提供真实评价、精确地址或即时确认。

## 本地预览

```bash
npm ci
npm run dev
```

## 自动发布

`main` 分支每次推送后，GitHub Actions 运行测试、构建并发布至 GitHub Pages。正式可查看的更新以成功部署为准。开发过程中的每次保存不会自动公开，避免半成品或错误代码出现在预览站。

本仓库只包含可公开的网页代码和示意图片。产品需求、合同设计和客户资料保存在仓库外。生产版需要独立接入真实房源、身份资格核验、工单、支付和签署等后端服务。
