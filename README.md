# 快旅居 · 网站页面预览

房屋租赁、旅居置换与物业托管的中英双语响应式页面原型。当前所有房源、图片和价格均为示意，不能预订、申请或交易；此版本不会收集用户联系方式。

## 本地预览

```bash
npm ci
npm run dev
```

## 自动发布

`main` 分支每次推送后，GitHub Actions 运行测试、构建并发布至 GitHub Pages。正式可查看的更新以成功部署为准。开发过程中的每次保存不会自动公开，避免半成品或错误代码出现在预览站。

本仓库只包含可公开的网页代码和示意图片。产品需求、合同设计和客户资料保存在仓库外。生产版需要独立接入真实房源、身份资格核验、工单、支付和签署等后端服务。
